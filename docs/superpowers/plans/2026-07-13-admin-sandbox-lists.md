# Account Sandbox Catalog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add account- and organization-scoped pages for region-filtered sandbox templates and region/template-filtered runner instances.

**Architecture:** Add user APIs backed by the selected account or GitHub installation Sandbox credentials, with an allowlisted region-to-endpoint mapping. Expose templates and runner-created instances as peer account-setting tabs.

**Tech Stack:** Go `net/http`, Qiniu Go SDK sandbox client, React, TypeScript, Tailwind/shadcn.

## Global Constraints

- Keep APIs user-scoped and never return Sandbox credentials.
- Edit `ui/`; do not hand-edit generated `internal/server/ui/` assets.
- Support `cn-yangzhou-1` and `us-south-1` consistently with account preferences.
